# La dispersión como política migratoria de desgaste

Este proyecto corresponde al front-end de la investigación [La dispersión como política migratoria de desgaste](https://tirandocodigo.mx/traslados-migracion/), el cual usa react, deck.gl y vite para crear una narrativa con scrolly telling y un mapa interactivo que permite ver los traslados origen-destino

Para levantar el proyecto en local necesitarás node y npm

## instala dependencias:

```
npm i
```

## levanta en local:

```
npm run dev
```

## compila para producción:

```
npm run dev
```
